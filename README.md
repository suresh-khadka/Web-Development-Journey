# 5th Semester Web Development Learning Journey

This repository contains a collection of learning materials, lab exercises, and projects completed during the 5th-semester Web Programming course. It serves as a comprehensive archive of the concepts and technologies explored during the semester.

## 🚀 Technologies Covered

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), jQuery, React
- **Backend:** Python, Django, Django REST Framework (DRF)
- **Others:** JSON, Git, Web Application Architecture

## 📁 Project Structure

The repository is organized into several folders based on topics and projects:

- `5th Sem Web Programming_course At home/`: Basic HTML and JavaScript exercises, DOM manipulation, and core programming concepts.
- `React/`: Projects and exercises built using the React library.
- `Django/`: Backend development projects using the Django framework.
- `jquery/`: Implementations and exercises using jQuery.
- `Web Application Lab/`: Lab assignments and practical implementations.
- `web_aplication_college_pratice/`: Practice projects developed for college coursework.
- `project_01/` & `project_02/`: small project implementations.
- `Daily-Topics_Wise-Code/`: Code snippets organized by daily learning topics.
- `Json files/`: Examples and data files using JSON format.

## 🛠️ Getting Started

Since this is a learning repository, most folders contain independent scripts or projects. To run specific projects:

1. **Frontend files:** Simply open the `.html` files in any modern web browser.
2. **React projects:** 
   - Navigate to the project folder.
   - Run `npm install` to install dependencies.
   - Run `npm start` to launch the development server.
3. **Django projects:**
   - Navigate to the project folder.
   - Set up a virtual environment: `python -m venv venv`
   - Activate it and install requirements: `pip install django` (and other needed packages).
   - Run migrations: `python manage.py migrate`
   - Start the server: `python manage.py runserver`
